DNS Transparent Proxy Detection Script – README

Overview

This PowerShell script runs a series of DNS tests to detect the presence of transparent DNS proxies, DNS manipulation, or unusual resolver behavior. It can run dig locally (if dig.exe is available) or remotely via SSH to a Linux/Unix host with dig installed.

The script supports 8 individual tests and an "All Tests" mode.

Requirements

Windows

  • PowerShell 5.1 or later (included in Windows 10/11)
  • dig.exe for Windows (optional if running locally)
    • Download from:
      • ISC BIND Windows ZIP (choose "BIND" → "Windows ZIP")
      • BIND9.net Download
    • Extract dig.exe into the same folder as this script.

Remote SSH Option

  • A Linux/Unix host with:
    • dig installed (sudo apt install dnsutils on Debian/Ubuntu, sudo yum install bind-utils on CentOS/RHEL)
    • SSH access enabled
  • Windows must have ssh.exe available (included in Windows 10/11).

Installation

  1. Download the script and save it as: 
    dns-proxy-test.ps1
  2. Optional: Download dig.exe for Windows and place it in the same folder as the script.
  3. Open PowerShell and navigate to the script folder: 
    cd "C:\path\to\script"
  4. Allow script execution (if not already enabled): 
    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Usage

.\dns-proxy-test.ps1

You will be prompted to:

  1. Choose local or remote mode.
  2. Select a root DNS server from the provided list.
  3. Select a test (1–8) or Run All Tests (option 9).

Test Descriptions

Test # Name Description PASS Criteria FAIL Criteria
1 NSID Check Sends an EDNS(0) NSID request to the root server. NSID is returned (server identity visible). No NSID returned (proxy may be stripping EDNS options).
2 RA Bit Check Queries root server with recursion disabled. RA bit is not set. RA bit is set (proxy may be answering recursively).
3 Custom EDNS Option Echo Sends a custom EDNS option (code 65001) with test data. Option is echoed back. Option missing (proxy may be altering packets).
4 Large DNSSEC UDP Response / TC Bit Requests DNSSEC DNSKEY with small buffer size (+ignore). TC bit is set (expected for large UDP responses). TC bit not set (proxy may be altering packet size or forcing TCP).
5 Malformed/Unusual Query Sends a mixed-case label with uncommon QTYPE (TYPE65). NXDOMAIN returned. Unexpected response (proxy may be rewriting queries).
6 Long Label + Private QTYPE Sends a long label with private-use QTYPE (65534). NXDOMAIN returned. Unexpected response.
7 Glue TTL Consistency Checks TTL values of glue A/AAAA records in Additional section. All TTLs match. TTLs inconsistent (proxy or resolver may be altering glue records).
8 Transparent Proxy Detection via Bogus IP Sends a standard DNS query to a non-existent IP address (192.0.2.123) with a short timeout (3s) and no retries.
  • DNS status: present → Transparent proxy likely (response from nonexistent IP)
  • Output contains "timed out" → No transparent proxy (query to nonexistent IP timed out)
 Unexpected output or no output at all.

Tips

  • If running remotely, ensure your SSH key or password authentication works before starting.
  • If you see "No output from dig", check firewall rules and that the root server IP is reachable.
  • You can add more root servers to the $rootServers array in the script.
